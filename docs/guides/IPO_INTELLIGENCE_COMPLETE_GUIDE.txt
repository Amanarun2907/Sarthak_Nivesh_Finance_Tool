═══════════════════════════════════════════════════════════════════════════
📝 EXAMPLE API CALL
═══════════════════════════════════════════════════════════════════════════

Python Example:
──────────────
import requests

url = "http://localhost:8000/api/ipo_intelligence/analyze"
data = {
    "company_name": "Tata Consultancy Services",
    "symbol": "TCS.NS",
    "issue_price": 3500.0
}

response = requests.post(url, json=data)
result = response.json()

print(f"Recommendation: {result['final_recommendation']}")
print(f"Overall Score: {result['overall_score']}")
print(f"Confidence: {result['overall_confidence'] * 100}%")

for agent in ['subscription', 'gmp', 'financials', 'listing', 'post_listing', 'risk']:
    agent_data = result[f'{agent}_score']
    print(f"\n{agent.upper()}: {agent_data['score']}/100")
    print(f"Recommendation: {agent_data['recommendation']}")


JavaScript/Frontend Example:
────────────────────────────
const response = await fetch('http://localhost:8000/api/ipo_intelligence/analyze', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        company_name: "Reliance Industries",
        symbol: "RELIANCE.NS",
        issue_price: 1450.0
    })
});

const result = await response.json();
console.log('Recommendation:', result.final_recommendation);
console.log('Overall Score:', result.overall_score);

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEM: "Module not found" errors
SOLUTION: 
    cd web\backend
    pip install -r requirements.txt

PROBLEM: "Port 8000 already in use"
SOLUTION:
    • Kill the process using port 8000
    • Or change port in START_COMPLETE_SYSTEM.bat:
      Change --port 8000 to --port 8001

PROBLEM: "Groq API error"
SOLUTION:
    • Check if GROQ_API_KEY is set correctly in START_COMPLETE_SYSTEM.bat
    • Current key: YOUR_GROQ_API_KEY_HERE

PROBLEM: Slow responses
SOLUTION:
    • Groq API is very fast (usually 2-5 seconds per agent)
    • All 6 agents run in sequence, total time: 12-30 seconds
    • This is normal for comprehensive analysis

PROBLEM: Test script fails
SOLUTION:
    • Make sure backend is running first
    • Check http://localhost:8000/health in browser
    • Run START_COMPLETE_SYSTEM.bat first, then TEST_IPO_INTELLIGENCE.py
