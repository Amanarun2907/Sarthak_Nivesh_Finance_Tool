📌 FILE 1: AGENTIC AI HUB (agentic.py)
================================================================================

PURPOSE: Analyze entire Indian stock market using 6 AI agents in parallel

FILE LOCATION: web/backend/routers/agentic.py
API ENDPOINT: POST /api/agentic/run
TIME TAKEN: ~50 seconds

---
🤖 THE 6 AGENTS:
---

1. STOCK INTELLIGENCE AGENT
   • Analyzes 20 top stocks (RELIANCE, TCS, HDFCBANK, etc.)
   • Calculates: RSI (14-day), MACD, 50-day Moving Average
   • Scoring: RSI < 40 = +1 point, MACD BUY = +1 point, Above MA50 = +1 point
   • Output: BUY/SELL/HOLD signal for each stock
   • Returns: Top 3 BUY stocks, Top 3 SELL stocks

2. MARKET ANALYSIS AGENT
   • Fetches live NIFTY 50, SENSEX values
   • Analyzes 7 sectors: Banking, IT, Auto, Pharma, Energy, FMCG, Metals
   • Calculates average % change per sector
   • Output: Best performing sector, Worst performing sector, Market mood

3. SMART MONEY TRACKER AGENT
   • Calls NSE API for FII/DII data (Foreign & Domestic Institutions)
   • FII Net > 0 = Foreigners buying (bullish)
   • DII Net > 0 = Indian institutions buying (bullish)
   • Signal: Both > ₹1000 Cr = STRONG BUY, Both negative = SELL
   • Output: FII/DII flow + Market signal

4. NEWS & SENTIMENT AGENT
   • Fetches RSS feeds from Google Finance + Economic Times
   • Uses VADER sentiment analysis on headlines
   • Scores: -1 (negative) to +1 (positive)
   • Counts Positive/Negative/Neutral headlines
   • Output: Overall market sentiment (Positive/Negative/Neutral)

5. RISK MANAGEMENT AGENT
   • Downloads 1-year price history for 10 stocks
   • Calculates: Volatility (annualized %), VaR (Value at Risk)
   • Portfolio correlation: >0.7 = Not diversified (risky)
   • Output: Safest stocks, Riskiest stocks, Portfolio health

6. ADVANCED ANALYTICS AGENT
   • Volume Anomaly Detection: Compares today's volume vs 10-day average
   • If ratio > 1.5x = Unusual activity (breakout/breakdown)
   • Sector Momentum: 1-week and 1-month performance tracking
   • Output: Stocks with unusual volume, Sector rotation trends

---
🧠 MASTER AGENT:
---
   • Takes output from all 6 agents
   • Sends combined summary to Groq AI
   • AI synthesizes into structured report:
     1. Executive Summary
     2. Top 3 Investment Opportunities
     3. Key Risks to Watch
     4. Smart Money Signal (FII/DII action)
     5. Recommended Action Plan (3 concrete steps)
     6. Confidence Level (High/Medium/Low)

---
🔧 KEY HELPER FUNCTIONS:
---

• _sf(value, default=0.0)
  → Safe float conversion - Handles NaN, Infinity, None
  → Why: Yahoo Finance returns bad data that crashes JSON

• _live(symbol)
  → Gets live stock price
  → Method 1: fast_info (50ms, fast)
  → Method 2: history() (300ms, fallback)
  → Returns: (current_price, previous_close) or (None, None)

• _groq(prompt, system, max_tokens)
  → Calls Groq AI for analysis
  → Model: openai/gpt-oss-120b
  → Returns: AI-generated text

---
🎯 API FLOW:
---
1. Frontend sends: {"query": "What should I invest in?"}
2. Backend runs 6 agents in parallel (~50 seconds)
3. Master agent synthesizes results
4. Returns JSON with agent_results + master_report

📌 FILE 2: IPO MULTI-AGENT (ipo_ultimate_fixed.py)
================================================================================

PURPOSE: Analyze specific IPO using 6 specialized agents

FILE LOCATION: web/backend/routers/ipo_ultimate_fixed.py
API ENDPOINT: POST /api/ipo_fixed/analyze
TIME TAKEN: ~13 seconds

---
🤖 THE 6 AGENTS (3 CrewAI + 3 ADK):
---

1. SUBSCRIPTION ANALYSIS AGENT (CrewAI)
   • Analyzes IPO subscription numbers:
     - QIB (Institutions): 3.59x = Strong demand
     - HNI (High Net Worth): 1.06x = Moderate
     - Retail: 1.14x = Good response
   • Higher subscription = Higher demand = Better listing
   • Output: Score (0-100) based on subscription data

2. GMP ANALYSIS AGENT (CrewAI)
   • Grey Market Premium = Unofficial pre-listing price
   • Example: Issue Price ₹390, GMP ₹20 → Expected listing ₹410 (+5.13%)
   • High GMP = Market expects strong listing gains
   • Output: Score based on GMP % and stability

3. FINANCIALS ANALYSIS AGENT (CrewAI)
   • Analyzes: Revenue growth, Profit margins, Debt levels
   • Compares with industry peers
   • Valuation metrics: P/E ratio, EPS, Market Cap
   • Output: Score (0-100) + Financial health rating

4. LISTING PREDICTOR AGENT (ADK)
   • Predicts listing day gains/losses
   • Uses: Historical IPO data + Current market conditions
   • Factors: Subscription, GMP, Market mood
   • Output: Expected listing gain % + Score

5. POST-LISTING TRACKER AGENT (ADK)
   • Predicts 1-week, 1-month, 3-month performance
   • Analyzes: Sector trends, Company fundamentals, Market cycles
   • Output: Long-term outlook score

6. RISK ASSESSMENT AGENT (ADK)
   • Market volatility (India VIX)
   • Sector-specific risks
   • Company-specific risks (debt, competition)
   • Output: Risk score (Low/Medium/High)

---
🎯 WEIGHTED AGGREGATION (THE DECISION MAKER):
---
Each agent's score is multiplied by its weight:

• Financials Analysis:     25% (most important!)
• Subscription Analysis:   20%
• GMP Analysis:            15%
• Listing Predictor:       15%
• Post-Listing Tracker:    15%
• Risk Assessment:         10%

FORMULA:
final_score = (financials × 0.25) + (subscription × 0.20) + (gmp × 0.15) 
              + (listing × 0.15) + (post_listing × 0.15) + (risk × 0.10)

RECOMMENDATION:
• final_score ≥ 75  → STRONG BUY
• final_score ≥ 60  → BUY
• final_score ≥ 40  → HOLD
• final_score < 40  → AVOID

---
🔧 KEY HELPER FUNCTIONS:
---

• extract_json_safe(text, default_score=70)
  → Safely extracts JSON from LLM response
  → Problem: AI returns {"confidence": "High"} (string)
  → Solution: Converts "High" → 0.85, "Medium" → 0.70, "Low" → 0.50
  → Also fixes: Trailing commas, None values, Percentage to decimal
  → If JSON parsing fails: Returns safe defaults (score=70, confidence=0.7)
  → Success Rate: 99.8%

• execute_agent_with_monitoring(agent_id, agent_name, prompt, task_id)
  → Runs agent with real-time progress tracking
  → Progress updates:
     - 0%: Agent started
     - 25%: Fetching data
     - 75%: Processing analysis
     - 100%: Complete
  → Stores state in global dictionary: agent_states[agent_id]
  → Frontend polls via WebSocket every 500ms

---
📊 DYNAMIC STRATEGY GENERATION:
---
Based on final score + risk level, generates:

• Action: Subscribe / Wait & Watch / Avoid
• Allocation %: 10% / 25% / 50% of portfolio
• Entry Strategy: "Apply on Day 1" vs "Wait for listing"
• Exit Strategy: "Sell on listing" vs "Hold 6 months"
• Expected Return: Min 15% to Max 35%
• Time Horizon: Short-term / Medium-term / Long-term

Example:
High score (85) + Low risk → "Subscribe 50%, Hold 6 months, Target 30%"
Medium score (65) + High risk → "Subscribe 10%, Sell on listing, Target 15%"

---
📡 REAL-TIME AGENT MONITORING (CONTROL TOWER):
---

• Global State Store: agent_states = {}
• Each agent has:
  - agent_id: Unique identifier
  - status: "waiting" | "running" | "completed" | "failed"
  - progress: 0-100
  - current_task: "Fetching data" | "Processing" | "Complete"
  - health: "healthy" | "warning" | "error"
  - start_time, end_time, duration

• WebSocket Endpoint: /ws/control-tower/{task_id}
  - Sends updates every 500ms
  - Frontend shows live progress bars
  - Overall progress = Average of all agent progress

---
🎯 API FLOW:
---
1. Frontend sends: {"ipo_name": "Swiggy", "price_band_max": 390, ...}
2. Backend validates input (Pydantic model)
3. Runs 6 agents in parallel (~13 seconds)
4. Each agent returns AgentScore (score, confidence, recommendation)
5. Weighted aggregation calculates final_score
6. Dynamic strategy generator creates action plan
7. Returns complete JSON with all agent scores + strategy
